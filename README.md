# 🚀 Autonomous Cloud Infrastructure Auditor & Remediator

A production-grade, API-driven cloud governance engine built with **Python**, **FastAPI**, and **AWS Boto3**. It automatically scans cloud environments to detect financial waste (unattached EBS volumes, idle EC2 instances) and security misconfigurations.

## 🛠️ Tech Stack
* **Backend:** FastAPI, Uvicorn
* **Cloud SDK:** AWS Boto3
* **Environment:** Python 3.x, REST API
